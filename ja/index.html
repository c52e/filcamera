01 / 機能

ネガから始めよう。

ファインダーから暗室まで、処理の流れを明示。ソースコードも確認できます。

01

センサーから RAW を取得

Camera2 で撮影し、完全な DNG を保持。利用可能な背面レンズを選択でき、実際のレンズ情報から 35 mm 換算焦点距離のクロップを計算します。

02

フィルムと印画紙のモデル

Spektrafilm に由来する分光処理パイプラインが、フィルム露出・現像・プリントを再現。それぞれの工程が仕上がりを決めます。

03

撮影時の色をプレビュー

デバイス内で LUT を生成し、選んだレシピの色をファインダーに反映。レシピを調整してもカメラの再起動は不要です。

04

Vulkan で動く暗室

RAW 現像とフィルムレンダリングをデバイスの GPU で実行。処理途中の浮動小数点画像も GPU 内に保持します。

05

撮影に必要な操作

露出補正、校正に基づくケルビン指定のホワイトバランス、タップでのピント合わせ。マニュアル操作の対応範囲はデバイスのカメラ API によって異なります。

06

現像し直せるオリジナル

写真の閲覧・共有・再現像に対応。新しい JPG バージョンを保存しながらオリジナル DNG を残し、後から調整を続けられます。

02 / 処理の流れ

センサーから、
プリント出力へ。

色は最終出力の前から形づくられます。RAW 現像でシーンデータを整え、フィルムと印画紙の工程で表現を決めます。

デバイス内で現像
  1. 01

    撮影とオリジナルの保持

    Camera2 RAW → 完全なオリジナル DNG。

  2. 02

    シーンの現像

    校正とデモザイク → クロップ、ProPhoto RGB、向きの処理。

  3. 03

    フィルム露出と現像

    フィルムの応答、DIR、粒状感、ハレーション、レンズ拡散。

  4. 04

    プリントと印画紙の現像

    プリント露光、分光フィルター、プリント拡散、印画紙の応答。

  5. 05

    スキャンと保存

    出力色処理 → RGBA8 読み戻し → JPG 95。

ファインダーは独立したプレビュー経路を使用

カメラ ISP → クロップと測光 → フィルム LUT → 画面

ライブプレビューはレシピの色を近似表示します。粒状感・拡散・ハレーションなどの空間効果は仕上がり写真に適用されます。ISP と RAW の入力にも違いがあります。

03 / 対応環境

カメラを知ろう。

公開 API がこのパイプラインを支えています。利用できる機能はデバイスの実装によって異なります。

Android 10+最小 Android バージョン
ARM64対応アーキテクチャ
Vulkan 1.1GPU API
60 MP最大有効 RAW 画素数

RAW 対応はデバイスによって異なります

対応する Camera2 Bayer RAW モードが必要です。レンズへのアクセス、物理ストリームの組み合わせ、マニュアル操作はデバイスに依存します。非対応カメラでは RAW 撮影できず、JPEG 撮影への自動切り替えも行いません。

現像には時間がかかります

フル解像度の処理は順番に実行され、数秒かかる場合があります。プレビューと仕上がりは完全には一致しません。デバイスごとの互換性確認が必要です。

自分のデジタルネガを再び現像

現在読み込めるのは FILCamera の現像記録が埋め込まれた DNG のみです。任意のサードパーティ製 DNG を扱う汎用インポーターではありません。

オリジナルをバックアップ

DNG はアプリ専用領域に、保存した JPG はシステムのギャラリーに保存されます。アンインストール前にオリジナルを書き出してください。ギャラリーのコピーはアプリ内ライブラリとは独立しています。
